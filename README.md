# Tic Tac Toe Game \n\n## Features \n- Classic Tic Tac Toe gameplay \n- Single player mode against AI \n- Multiplayer mode \n- Responsive design \n- Simple and intuitive UI \n\n## Installation \nTo get started with the Tic Tac Toe Game, follow these instructions: \n1. Clone the repository: \n   ```bash \n   git clone https://github.com/lanadamica17-ui/tictactoe-game.git \n   ``` \n2. Navigate into the project directory: \n   ```bash \n   cd tictactoe-game \n   ``` \n3. Install the dependencies: \n   ```bash \n   npm install \n   ``` \n\n## Usage \nTo run the game, execute the following command: \n```bash \nnpm start \n``` \nYou can then open your browser and navigate to `http://localhost:3000` to play the game! \n\n## Contributing \nWe welcome contributions to the Tic Tac Toe Game!
